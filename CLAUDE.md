# SideStoreInstaller
Script PowerShell (`sidestore-installer.ps1`) + README. Repo: github.com/RubenAguado/SideStoreInstaller (rama `master`).
Instala SideStore en iPhone/iPad desde Windows (driver Apple + iloader); modos Instalar / Pairing / Limpiar.
Sin despliegue: se copia a la torre Windows. Sin secretos. Push manual: `git add -A && git commit && git push`.
Script solo ASCII (PowerShell 5.1 lee mal UTF-8 sin BOM). Validar sintaxis con pwsh antes de subir.
